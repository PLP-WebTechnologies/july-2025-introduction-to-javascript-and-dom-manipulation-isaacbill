# 🛍️ Mini Shopping Cart (JavaScript Fundamentals Project)

This project is part of a **JavaScript Fundamentals assignment** where we explore core JS concepts such as **variables, conditionals, functions, loops, and DOM manipulation** — all applied to a real-life example: a mini shopping cart.

---

## 🚀 Features
- ✅ **Check Age** — tells if the user is old enough to shop independently.
- 👋 **Welcome Greeting** — greets the shopper dynamically.
- 🛒 **Shopping Cart System**:
  - Add items with a name and price
  - Remove items with one click
  - Running total updates automatically
- 💸 **Discount Code**:
  - Enter `SAVE10` to apply a 10% discount
- ⏳ **Countdown Timer**:
  - Simple countdown demo using a while loop
